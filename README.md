
# Contacts Manager 1.0

Веб-приложение для управления контактами, разработанное на Python с использованием Flask.

## Возможности

- Добавление контактов.
- Просмотр списка контактов.
- Поиск по имени или номеру телефона.
- Удаление контактов.
- Сохранение данных в JSON.

## Используемые технологии

- Python 3.14
- Flask
- HTML
- CSS
- JSON

## Структура проекта

- app.py — обработка запросов (View).
- models.py — модель и управление контактами (Model).
- templates/index.html — HTML-шаблон (Template).
- contacts.json — хранение контактов.
- requirements.txt — зависимости проекта.

## Установка

Установите зависимости:

```bash
py -3.14 -m pip install -r requirements.txt
```

## Запуск

Выполните команду:

```bash
py app.py
```

Откройте браузер:

http://127.0.0.1:5000
